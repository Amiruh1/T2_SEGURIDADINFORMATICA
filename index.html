Semana 7 y 8

Reconocimiento · Scanning · Explotación · Persistencia · MitM

🔍 Scanning de vulnerabilidades: concepto y propósito

El scanning de vulnerabilidades es un proceso automatizado que permite identificar debilidades de seguridad en sistemas, redes, aplicaciones y servicios. A diferencia de una auditoría manual, las herramientas de scanning recorren cientos o miles de activos en cuestión de horas, detectando configuraciones inseguras, software desactualizado, puertos abiertos innecesarios, credenciales débiles y servicios mal configurados. Este proceso es fundamental en cualquier programa de ciberseguridad porque proporciona una visión general del estado de salud de la infraestructura y ayuda a priorizar los parches críticos.

Los scanners más avanzados utilizan bases de datos actualizadas de vulnerabilidades conocidas, como el sistema CVE (Common Vulnerabilities and Exposures) y el estándar CVSS (Common Vulnerability Scoring System) que asigna una puntuación de gravedad (de 0 a 10) a cada fallo. Ejemplos de herramientas líderes son Nessus (muy usado en entornos corporativos), OpenVAS (alternativa open source), QualysGuard (solución cloud) y Nexpose de Rapid7, que se integra directamente con Metasploit para facilitar pruebas de penetración.

⚙️ Metasploit Framework: arquitectura y componentes

Metasploit Framework (MSF) es una plataforma modular escrita en Ruby que se ha convertido en el estándar de facto para pruebas de penetración y desarrollo de exploits. Su arquitectura basada en módulos permite una gran flexibilidad: exploits (código que aprovecha una vulnerabilidad específica), payloads (código que se ejecuta tras el exploit, como shells reversas o descarga de malware), auxiliares (escáneres, fuzzing, ataques de fuerza bruta) y post-explotación (técnicas para mantener acceso, extraer hashes, pivoting).

Entre los payloads más conocidos están meterpreter (shell avanzada con capacidades de inyección de comandos, captura de pantalla, descarga de archivos) y reverse_tcp (shell reversa que evade firewalls). Metasploit también incluye herramientas de evasión de antivirus y generación de payloads ofuscados.

msfconsole > use exploit/windows/smb/ms17_010_eternalblue
set RHOSTS 192.168.1.100
set PAYLOAD windows/x64/meterpreter/reverse_tcp
exploit

⚠️ Explotación local vs remota: diferencias y técnicas

La explotación remota ocurre cuando el atacante no tiene acceso previo al sistema objetivo y se aprovecha de servicios expuestos en red. La explotación local asume que el atacante ya tiene algún nivel de acceso y busca elevar privilegios a root o SYSTEM. Las señales de una explotación remota incluyen picos anómalos de tráfico, errores con stack traces, nuevas cuentas de usuario inesperadas y conexiones salientes a IPs sospechosas.

🕵️ Persistencia, backdoors y shell reversa

Persistencia se refiere al conjunto de técnicas que utiliza un atacante para asegurar que su acceso al sistema comprometido se mantenga incluso después de reinicios. Una shell reversa es un tipo de backdoor donde la máquina víctima inicia la conexión hacia el atacante, evadiendo firewalls y NAT. Herramientas como Netcat, Metasploit o PowerCat permiten establecer shells reversas.

🧹 Limpieza de huellas y manipulación de logs

Después de lograr sus objetivos, un atacante experimentado intenta borrar, alterar o deshabilitar las evidencias de su actividad. Las técnicas incluyen: borrar entradas específicas de logs, desactivar servicios de auditoría, modificar timestamps de archivos y usar rootkits. Los logs son la principal fuente de evidencia forense.

🌐 Ataque Man-in-the-Middle (MitM) con Ettercap

El ataque Man-in-the-Middle consiste en interponerse en la comunicación entre dos partes. Las técnicas más comunes son ARP spoofing y DNS spoofing. Ettercap es una herramienta open source que facilita estos ataques.

# Ejemplo básico de ARP spoofing con Ettercap
sudo ettercap -T -M arp:remote /192.168.1.1// /192.168.1.100//
Seguridad Perimetral

Firewalls · Zona Desmilitarizada · IDS/IPS · Cisco ASA

🔥 Firewall: definición, tipos y filosofías

Un firewall es un sistema de seguridad que controla el tráfico de red basándose en reglas predefinidas. Existen tipos: filtrado de paquetes, stateful inspection y firewalls de aplicación. La filosofía más recomendada es "todo prohibido, excepto lo permitido".

🌐 Zona Desmilitarizada (DMZ): concepto y arquitectura

Una DMZ es una subred aislada que actúa como área intermedia entre la red interna e Internet. En ella se ubican servicios accesibles desde el exterior (web, correo). Su objetivo es reducir la superficie de ataque.

⚠️ IPS vs IDS: prevención y detección de intrusiones

El IDS detecta y genera alertas pero no bloquea; el IPS actúa en línea y bloquea automáticamente el tráfico malicioso. Se complementan con firewall para defensa en profundidad.

⚙️ Configuración básica en Cisco ASA

interface GigabitEthernet0/0
nameif inside
security-level 100
ip address 192.168.1.1 255.255.255.0
no shutdown

interface GigabitEthernet0/1
nameif outside
security-level 0
ip address 200.100.50.1 255.255.255.0
no shutdown

object network RED_INTERNA
subnet 192.168.1.0 255.255.255.0
nat (inside,outside) dynamic interface

access-list OUTSIDE_IN extended permit tcp any any eq 80
access-list OUTSIDE_IN extended permit tcp any any eq 443
access-group OUTSIDE_IN in interface outside

El security-level va de 0 (menos confiable) a 100 (más confiable). Las ACL permiten tráfico específico.

🔐 Buenas prácticas y recomendaciones finales

Filosofía "todo prohibido excepto lo permitido", implementar DMZ, combinar firewall con IPS/IDS, actualizar firmas, principio de mínimo privilegio y pruebas de penetración periódicas.
